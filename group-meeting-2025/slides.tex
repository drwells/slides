\section{History}
\begin{frame}

  \begin{itemize}
    \item[$\blacksquare$] Work towards Marshall's thesis and the Langtangen prize: we were

\begin{frame}

  IBAMR:
  \begin{itemize}
    \item[$\blacksquare$] IBAMR gets a proper test suite, replacing the one built solely on examples

\begin{frame}[fragile]
  \frametitle{Specifications of stresses}
  FCH-EP uses 24 such definitions:
  \lstset{language=c}
  \begin{lstlisting}
// anterior mitral valve marginal chordae
ForceContribution_AMVL_marginal {
   type                  = "nonlinear_spring"
   a                     = 1.6181e8
   a_f                   = 1.678783e9
   index_f               = 0
   material_ids          = 107, 109, 112, 117, 118
   even_order_quadrature = TRUE
   n_points_1D           = 1
}
  \end{lstlisting}
  \begin{itemize}
    \item[$\blacksquare$] SAMRAI's input database format is pretty good
    \item[$\blacksquare$] \texttt{material\_id}s are ExodusII block ids
    \item[$\blacksquare$] \texttt{n\_points\_1D} is deal.II jargon (number of quadrature points
      in the equivalent-order 1d rule: this rule is second-order accurate and
      has four points)
    \item[$\blacksquare$] \texttt{even\_order\_quadrature} means to use the even-degree
      Witherden-Vincent rule (fewer points for at least second-order accurate)
  \end{itemize}
  \end{frame}

\begin{frame}
  \frametitle{How do active strains and stresses work together?}
  We have multiple implementations of active strain (see Marshall's thesis),
  and multiple stress functions: how do we keep it sorted?
  \begin{itemize}
  \item[$\blacksquare$] \texttt{fsi::MechanicsValues} computes the deformation gradient,
    invariants, etc.
  \item[$\blacksquare$] That class computes $\mathbb{F}_E = \mathbb{F} \mathbb{F}_A$, which is
    what the stresses see as ``$\mathbb{F}$''
  \item[$\blacksquare$] Stresses compute $\mathbb{P}_E(\mathbb{F}_E)$
    $\mathbb{P} = \det(\mathbb{F}_A) \mathbb{P}_E(\mathbb{F}_E) \mathbb{F}_A^{-T}$
  \item[$\blacksquare$] It ``fixes'' the stresses (a pull-back) via
    $\mathbb{P} = \det(\mathbb{F}_A) \mathbb{P}_E(\mathbb{F}_E) \mathbb{F}_A^{-T}$
  \item[$\blacksquare$] This doesn't effect the penalties at all (nice tensor calculus exercise)
  \end{itemize}
\end{frame}

\begin{frame}
  \frametitle{Saving Output}
  This could be improved, especially on the EP side.
  \begin{itemize}
    \item[$\blacksquare$] Goal: no more munging log files, unknown units (use CGS)
    \item[$\blacksquare$] \texttt{fsi::StatisticalOutput} collects all flow rate, pressure data,
      etc. which is an average or point evaluation
    \item[$\blacksquare$] Writes HDF5, in restart database
    \item[$\blacksquare$] Same for the ParaView series file: no need to manually edit, the
      correct version is always available after restarts
  \end{itemize}

  \vfill
  We need better documentation on using VisIt, ParaView, managing session files,
  scripting, etc. (some work is being done by Perry)
\end{frame}

\begin{frame}
  \frametitle{Plugins}
  If you need a new stress function, just write it and add it with a callback in
  \texttt{main()}.
  \begin{itemize}
    \item[$\blacksquare$] Same with circulation models, visualization, etc.
    \item[$\blacksquare$] \texttt{main\_ep\_fsi3d} is essentially a bunch of callbacks on top of
      the normal FSI stuff: source code is mostly plugins
  \end{itemize}

  \vfill
  This isn't well documented, nor do we have great examples. Everything works but it
  is difficult to use without asking me or Marshall about it.
\end{frame}
